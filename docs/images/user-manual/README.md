# User Manual Screenshots

Lagay lamang ang mga screenshot dito. Ang filenames ay dapat eksaktong tugma sa nakasaad sa `USER_MANUAL.md` (bandang huli: "Appendix A: Screenshot Checklist").

## Paano kumuha ng screenshot
1. Buksan ang app sa browser (naka-log in bilang tamang role).
2. Siguraduhin na nakikita ang buong page (kung hindi, i-crop o bawasan ang zoom).
3. I-save ang image bilang `.png` gamit ang eksaktong filename sa ibaba.
4. I-drop ang files sa folder na ito, pagkatapos i-commit at i-push.

> Kapag bukas ang isang page sa bagong browser/device, tingnan kung may kakaibang branding (logo/school name) na naka-save per-browser.
